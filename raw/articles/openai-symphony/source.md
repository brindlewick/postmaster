README and specification of an open-source orchestrator published under the openai organisation: it reads tickets from a tracker, runs one coding agent per ticket in an isolated workspace, and ends runs at a handoff state such as Human Review. Bears on tracker-driven different-task runs, a human gate at the end, and logging. Read as raw files at the commit named in the url, plus GitHub API numbers.
