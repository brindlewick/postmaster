An individual Internet-Draft that specifies a JSON log record for AI agent actions, chained by hashes. Bears on group 5 (a closed set of action types, tamper-evidence and its stated limits, delegation between agents). Read as the draft text and its status page through a fetch tool that returns a processed copy; the text was fetched twice with different prompts, the status page once. Not an IETF standard: the status page reports an individual submission with no working-group adoption.
