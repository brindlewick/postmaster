The OpenTelemetry convention for spans that describe an agent run: creating an agent, invoking an agent or a multi-agent workflow, planning, and executing tools. Bears on group 5 (the standard vocabulary a trace of an agent run can use; its status). Read the front of the file, the workflow, tool and command-execution sections and the attribute tables by searching it; not every one of its 1,646 lines. The older address opentelemetry.io/docs/specs/semconv/gen-ai/gen-ai-agent-spans/ now only says the conventions moved to this repository.
