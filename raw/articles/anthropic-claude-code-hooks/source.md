Vendor documentation of Claude Code's lifecycle hooks: the events, the JSON each hook receives (session id, prompt id, transcript path, agent id) and subagent behaviour. Bears on group 5 (hooks are the mechanism that third-party audit tools such as Entire, git-ai and Langfuse's integration build on). Read as a documentation page through a fetch tool that returns a processed copy; fetched twice with different prompts, and passages are marked checked only where both fetches gave the same words.
