Open-source set of skills that make a coding agent brainstorm a design, get the person's approval of a written spec and a written plan, and then run subagents per task with reviews. Bears on a person's sign-off before code, on independent reviewers and on a capped fix loop. Read as raw files at the commit named in the url.
