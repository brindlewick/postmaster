A local engine that turns a ticket into a pull request: several models draft and vote on the plan (a "council"), the person signs off the spec, one implementer works in a git worktree, and state is kept in logs. It bears on the combination's independent drafts, selection or synthesis, and spec sign-off points. Read as the raw README text (431 lines).
