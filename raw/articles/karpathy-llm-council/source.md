A small local web app that sends one query to several models through OpenRouter, has them rank each other's anonymised answers, and has a chairman model write the final answer. It bears on claim 3 (a model that reads several answers and writes one) and on how widely the council idea is used. It is not coding specific. Read as the raw README text (87 lines).
