README of a small plugin that runs several candidates of one model on the same task, ranks the trajectories with a verifier, and can apply the winner. It reports the upstream method's numbers and its own small measurements with caveats. Bears on claim 3 (selecting among candidates) and on the independence of the selector. Read as the raw README at the commit named in the url, plus GitHub API numbers.
