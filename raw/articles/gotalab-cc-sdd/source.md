Open-source spec-first skill set modelled on Kiro: the agent writes requirements, design and tasks, humans approve at phase gates, and approved tasks then run with a fresh implementer, an independent reviewer and a capped debug loop per task. Bears on a person's sign-off before code and on a capped review loop. Read as raw files at the commit named in the url.
