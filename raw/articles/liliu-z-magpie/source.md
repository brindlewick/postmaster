A command-line tool in which several vendors' CLI agents review one pull request independently, debate for up to a set number of rounds, and a verifier agent checks each finding against the code. It is the tool behind the Milvus debate post. Read as the raw README text (657 lines), the opening, provider table and configuration lines.
