Captured for #300's research on functional programming, formal verification and AI coding: Each routine carries a precondition (the caller's obligation) and a postcondition (the routine's), each class an invariant, all written as Boolean expressions that can be checked at run time during development; a violated precondition is a bug in the caller and a violated postcondition a bug in the routine.
