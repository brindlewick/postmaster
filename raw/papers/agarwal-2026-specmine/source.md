A data-set paper that counts spec files that spec-first tools leave in public GitHub repositories (July 2026 snapshot), tool by tool. It is the nearest thing to an independent measure of use of these tools; it measures neither approval by a person nor outcomes. Read as abstract page plus full text (four fetches).
