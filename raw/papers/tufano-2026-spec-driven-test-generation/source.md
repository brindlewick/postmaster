A workshop paper on making an agent write down pre-conditions, post-conditions and undefined behaviour before it writes tests. The specification is written by the agent, and the evaluation skipped the human-in-the-loop step, so it shows what a spec-first step does without a person's sign-off. Software-engineering evidence (test generation, 90 real bug fixes). Read as abstract page plus full text (two fetches).
