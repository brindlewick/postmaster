An evaluation framework (BenchAgent) that runs one single-agent anchor and six multi-agent workflows under one protocol with one model on ten benchmarks, two of them function-level coding (HumanEval, MBPP); it bears on group 6 and on whether more agents help. Read as full text (HTML, two fetches) plus the abstract page. A preprint; the code is on the BenchAgent branch of the MASArena repository.
