A single-author arXiv preprint (cs.SE, v1, no venue) on two different models on code synthesis: a plan from a reasoning model before the code hurt, a review after the code helped, and the benefit of review grew with how rich the specification was. Software-engineering evidence at function level (HumanEval+, MBPP+); no person approves anything. Read as abstract page plus full text (two fetches of the full text).
