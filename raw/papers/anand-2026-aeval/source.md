A workshop paper (ICML 2026 workshop, per the abstract page) on a continuous-integration framework that tests agent skills deterministically and keeps the executor apart from the grader. It is the closest write-up found to testing an agent workflow itself rather than a model; it is not about several vendors' models. Abstract page only, read once.
