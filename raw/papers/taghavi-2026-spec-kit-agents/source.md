A preprint that adds read-only probing and validation hooks to each stage of the Spec Kit workflow, run by a product-manager agent and a developer agent, and scores 128 runs with an LLM judge. Its plan-review checkpoints are auto-approved, so it shows what the spec workflow does with no person signing off, against a baseline that skips the spec artifacts. Software-engineering evidence (feature tasks in five repositories; SWE-bench Lite). Read as abstract page plus full text (three fetches).
