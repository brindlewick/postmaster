Captured for #300's research on functional programming, formal verification and AI coding: A pipeline in Lean that tests each model-written specification with randomised property-based tests before any code is written certified 28 of 50 LeetCode-style problems against 17 for a single-mode Lean baseline at a $5 budget per problem, and the same tests found 16 defective reference specifications in Verina and 18 in CLEVER.
