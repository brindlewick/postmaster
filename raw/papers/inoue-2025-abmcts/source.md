Adaptive Branching Monte Carlo Tree Search (AB-MCTS) decides between sampling a new answer and refining an existing one; the paper's evaluation is on coding and engineering tasks, with a multi-LLM variant in Appendix D. Mostly code evidence, so it is recorded here as code; the multi-LLM ARC-AGI-2 result (solutions written as Python programs) is taken from the vendor blog in the articles folder because the fetched paper text stopped before the multi-LLM results. Peer reviewed (NeurIPS 2025 spotlight per the arXiv comment).
