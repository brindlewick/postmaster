Universal Self-Consistency (USC): the model that wrote N samples is asked to pick the most consistent one, so voting works for free-form output. It is a selection method, not a synthesis method, so it bears on claim 3 only as the "pick" side. Math, QA and summarization are general; BIRD-SQL and ARCADE are code and are reported separately.
