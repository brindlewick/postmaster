title: Do LLMs generate test oracles that capture the actual or the expected program behaviour?

Captured for #300's research on functional programming, formal verification and AI coding: A model asked to classify or write test assertions for Java code tends to accept or produce assertions that match what the code actually does, including buggy code, rather than what it should do.
