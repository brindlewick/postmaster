## says

A coding agent that reads a Python module, infers properties from code, docstrings and usage, writes Hypothesis tests and triages the failures produced 984 bug reports over 100 packages, and of 50 reports two authors scored, 56% were valid and 32% worth reporting.

## measured

TASK: find properties of functions and across functions (invariants, round trips, inverses, metamorphic relations), write Hypothesis tests, run them, and decide whether a failure is a real bug with a three-step rubric (reproducible; legitimate, meaning realistic inputs and a property the code claims; impact). SPEC WRITER: the model, from code and documentation; no human-written reference. SUBJECTS: 100 packages (15 standard-library modules and 15 third-party packages hand-picked, 70 random from the top 5,000 on PyPI), 933 modules, 984 reports covering 786 modules. JUDGED BY: two authors independently scored 50 randomly sampled reports (from the top 80% by the agent's own rubric score), settling disagreements by discussion; inter-rater agreement on the first pass was kappa 0.31 (Sec 4, second read), so the two reviewers disagreed on a good share of reports before consensus; all 21 top-scoring reports were reviewed. MODEL: Claude Opus 4.1 in Claude Code. NUMBERS: 56% valid (95% CI 42.2-69.8) and 32% valid and reportable (95% CI 19.1-44.9) from the n=50 sample; top 21 reports: 18 valid (86%) and 17 reportable (81%); 5 reported, 4 with patches, 3 merged (NumPy, AWS Lambda Powertools, tokenizers); cost $5.56 per report and $9.93 per valid bug, $5,474 and 136.6 hours in all. Example bugs: numpy.random.wald returning negative samples (the property "samples are non-negative"); a slicing helper that returns the first chunk repeatedly; an item hash that hashes every list to the same value.
