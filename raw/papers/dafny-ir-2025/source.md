title: Dafny as Verification-Aware Intermediate Language for Code Generation
author: Li, Zetzsche, Somayyajula
---
Captured for #300's research on functional programming, formal verification and AI coding: In a prototype where the model writes Dafny from a prose request, confirms its reading with the user in prose, and compiles verified Dafny to Python, 77% of 164 HumanEval tasks passed all tests, against 86% when the same model wrote Python directly.
