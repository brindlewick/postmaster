title: Harnessing Code Agents for Automatic Software Verification (system name Aria)
author: Kan, Kan, Ertel
---
Captured for #300's research on functional programming, formal verification and AI coding: A general coding agent wrapped in a verification harness re-proved every lemma it was given in the Iris separation-logic library (4,257 lemmas), 217 lemmas in Rust's standard libraries built on it, and 318 in a regular-language library, with no Coq expert intervention, using Claude Opus 4.7; the lemma statements come from public libraries and no held-out set was used.
