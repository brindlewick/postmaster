author: Seonglae Cho, Donghyun Lee

A protocol that lets two coding agents edit one shared file system through claim and status tools, compared with one agent and with two agents whose outputs are merged afterwards, on four backend coding tasks with vendor coding CLIs; it bears on group 6 (newer and small). Read as full text (HTML v1, two fetches) plus the abstract page; a preprint. Scoring is mainly by an LLM judge and by whether an agent abandons the task, not by hidden tests; cell sizes are small (n=3 to 35 per one fetch).
