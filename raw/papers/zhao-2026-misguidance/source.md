title: Evaluating and Mitigating the Misguidance Effect of Buggy Code in LLM-Generated Unit Tests
author: Zhao, Zhou, Cohen
---
Captured for #300's research on functional programming, formal verification and AI coding: When models are shown buggy code, they write about eight times as many tests that assert the bug's behaviour (3.84% of tests against 0.46% with the fixed code) and about a third as many tests that expose it, and replacing the code in the prompt with a model-written specification docstring reduces this.
