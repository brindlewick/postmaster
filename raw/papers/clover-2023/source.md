title: Clover: Closed-Loop Verifiable Code Generation
author: Sun, Sheng, Padon, Barrett
---
Captured for #300's research on functional programming, formal verification and AI coding: Rather than trust a verifier on code the model also annotated, Clover checks that code, docstring and formal annotations agree with each other, using the verifier plus the model, and on its small test set it accepted 87% of correct programs while accepting none of the deliberately wrong ones.
