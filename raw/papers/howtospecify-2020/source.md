Captured for #300's research on functional programming, formal verification and AI coding: A tutorial gives five ways to write properties for pure code (validity invariants, postconditions, metamorphic, inductive, model-based), compares them on eight planted bugs in a binary search tree, and says that newcomers find it hard to identify properties to write.
