A single-author preprint whose abstract states a 73% reduction in security defects from putting security rules into the specification. The table behind it is 3 against 11 counted violations, from one developer building one banking application twice in two weeks. It is the source of the 73% figure that a later preprint repeats. Software-engineering evidence (one case study). Read as abstract page plus full text (two fetches).
