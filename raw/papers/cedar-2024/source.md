Captured for #300's research on functional programming, formal verification and AI coding: AWS wrote an executable model of Cedar in Lean and proved properties of it, checked the Rust production code against the model with differential random testing, and used property-based tests for the rest; proofs found 4 bugs and the testing 21 more.
