Captured for #300's research on functional programming, formal verification and AI coding: Given a formal specification, off-the-shelf models produce verified code for 82% of Dafny tasks, 44% of Verus tasks and 27% of Lean tasks when a task counts as solved if any one model solved it; the best single model solves far fewer.
