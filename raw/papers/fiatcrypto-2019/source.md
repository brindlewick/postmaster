Captured for #300's research on functional programming, formal verification and AI coding: A Coq-checked generator for cryptographic arithmetic replaced hand-written code in BoringSSL, so that the code behind most browser TLS handshakes in 2018 was machine-proved, with the proof covering one algorithm for many parameter sets.
