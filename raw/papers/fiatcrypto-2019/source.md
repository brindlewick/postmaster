Captured for #300's research on functional programming, formal verification and AI coding: A Coq-checked generator for cryptographic arithmetic replaced hand-written code in BoringSSL, so that, by the authors' estimate, about half of the HTTPS connections that browsers open use the verified field arithmetic, with the proof covering one algorithm for many parameter sets.
