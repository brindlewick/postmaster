Preprint (cs.SE, v1) on agent-based ensemble reasoning for SWE-bench issue resolution: a coder agent generates candidate patches, a tester agent filters them with regression tests, and a selector agent picks one by repeated selection and majority vote. It bears on claims 1, 2 and 3 for coding, because it has a setting that mixes three vendors' models.
