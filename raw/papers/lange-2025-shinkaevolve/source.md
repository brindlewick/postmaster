Preprint on evolutionary search where models rewrite programs, with a bandit that picks which of several models to call. It is code optimisation and program search, not issue resolution. It bears on claims 1 and 2 only through one ablation of an ensemble against a single weak model. Abstract read through the arXiv listing; full text read once.
